# Installation

## Requirements

- **Node.js** 22 or later
- **pnpm** 9+ (recommended), npm, or yarn

## Install globally

```bash
npm install -g @ndnci/translify
```

```bash
pnpm add -g @ndnci/translify
```

## Use without installing

```bash
npx @ndnci/translify@latest --help
```

```bash
pnpm dlx @ndnci/translify@latest init
```

## Verify installation

```bash
translify --version
```
